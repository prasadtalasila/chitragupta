# 🎨 House styles

Status: **reference.** The style layer of the
[writing standards](../../WRITING-STANDARDS.md), listed in the core's
index.

This folder is for house styles: a named set of conventions a venue or
a publisher imposes, beyond what the core and the element files settle.
It holds no style yet.

A draft's own style is a different thing and does not live here. The
house-style decisions for one draft are recorded in its dossier's
`scope.md` (the core's §8), and the style learnt from example papers
that #1181 proposes would be a per-draft `style.md` in the dossier as
well, with any conflict against these standards recorded there by
section number.
