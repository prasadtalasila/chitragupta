# 🧭 Genre files

Status: **reference.** The genre layer of the
[writing standards](../../WRITING-STANDARDS.md), listed in the core's
index.

**Written for** whoever moves a genre's writing rules out of its skill,
and for the skills that will read the result. **Assumed:** the core,
[WRITING-STANDARDS.md](../../WRITING-STANDARDS.md), and
[GENRE.md](../../GENRE.md) for which skill writes which genre.

This folder holds no genre file yet. It will hold one per genre, named
by the genre's `--genre` value (`survey.md`, `thesis-chapter.md`,
`research-paper.md`), each saying:

- what the genre owes its reader;
- its reread checklist, the genre's form of the core's §6;
- how rare figures and numbered equations are in it;
- its unit for the core's §11, which the table there already states.

A genre file follows the rules the core's index sets for every layer
file: it opens with "Assumes the core, §1–9", repeats no other file's
text, numbers any section it adds with a number no file has used, and
is a row of the index table. Procedure a skill follows, as opposed to a
rule a draft is held to, stays with the skill.
